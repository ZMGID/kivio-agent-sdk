# Origin

This repository starts from the Kivio [source snapshot at commit 126547462cee9bb4cde7544270e96c163a86296e](https://github.com/ZMGID/kivio/commit/126547462cee9bb4cde7544270e96c163a86296e). Access to the upstream repository may be restricted.

The SDK runtime source, examples, Rust tests, and license were copied unchanged. The SDK retains its [GPL-3.0-or-later license](../LICENSE). The independent consumer and the boundary checker came from the same snapshot. Their paths and repository-specific metadata were adapted for this standalone repository.

This repository is a snapshot. Changes made here or upstream do not flow to the other repository automatically. Future synchronization requires a deliberate port.
